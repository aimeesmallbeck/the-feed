### 2. Frontend Asset URL Access (Major Fix)
**Problem:** Static HTML/JS files weren't accessible via URLs - only viewable in editor.

**Root Cause:** OpenClaw sandbox doesn't serve files directly. Need proxy pass or Canvas control.

**Solution:** Control browser directly via OpenClaw's `browser` tool.

**Pattern Established:**
```python
# Standard file access pattern for workspace files
1. Read file (for editing)
2. browser(open + snapshot) (for viewing/JS execution)
```

**Files Worked On:**
- `frontend/index.html` - Main IDE interface
- `frontend/css/styles.css` - Styling
- `frontend/js/app-loader.js` - App loading logic (loads swagger-editor)
- `frontend/index2.html` - Alternative IDE interface

**Canvas Control Method:**
```bash
openclaw canvas present --url <url>  # Opens webpage
openclaw canvas snapshot             # Captures rendered state
```

**Key Insight:** For interactive apps (IDE, docs, tools), need `pty=True` on exec calls to handle TTY requirements properly.
