## Platform-Specific Tips

### Midjourney (Discord)
- Use `/imagine` command
- Add `--ar 9:16` for vertical format
- Use `--v 6` for latest version
- Generate multiple variations, pick best
- Download at full resolution

### Gemini Veo
- Limited generations per day (check your quota)
- Prioritize motion-heavy clips
- Use specific camera directions
- Keep prompts under 100 words
- Generate during off-peak hours for faster processing

### CapCut AI
- Mobile app only
- Good for quick tests
- Limited control vs Gemini
- Best for simple scenes
- Free tier available

### ElevenLabs
- Use "Conversational" or "Storytelling" voice styles
- Adjust stability (lower = more emotion)
- Add pauses with "..." or line breaks
- Generate multiple takes, pick best

## Troubleshooting

### If Midjourney images look wrong:
- Add `--style raw` for more realistic
- Increase `--stylize` value (50-250)
- Try different aspect ratios
- Use image prompts as reference

### If Gemini videos are low quality:
- Simplify the prompt
- Focus on one action
- Remove complex camera movements
- Try during off-peak hours

### If CapCut AI fails:
- Use simpler prompts
- Try different style presets
- Check internet connection
- Clear app cache

### If voiceover sounds robotic:
- Lower stability setting
- Add more natural pauses
- Try different voice model
- Adjust speed slightly
