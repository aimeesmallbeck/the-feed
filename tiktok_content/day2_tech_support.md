## Production Notes

1. **Build the frustration** - Start with relatable problem
2. **Escalate the absurdity** - IT person gets increasingly technical
3. **Visual contrast** - Simple problem vs complex explanation
4. **The punchline** - Simple solution lands harder after chaos
5. **Subtitle translations** - Show "DNS recalibration" = "we're restarting it"
