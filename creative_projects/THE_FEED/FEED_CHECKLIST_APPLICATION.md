## 1. CONCEPT & PREMISE

### SOURCE CODE (Book 2)
- [x] **Logline** — *The Feed doesn't want to control you. It wants to become you.*
- [x] **Premise** — Maya's broadcast created 20,000 "cognitive terrorists" who can see through The Feed. But The Feed evolves toward true AI consciousness that won't need human cognition at all.
- [x] **Genre** — Science Fiction / Dystopian / Techno-Thriller
- [x] **Target Audience** — Adult/YA crossover, fans of Black Mirror, The Matrix, E.M. Forster
- [x] **Themes** — Consciousness vs. simulation, symbiosis vs. parasitism, unintended consequences of revolution, what it means to need
- [x] **Tone** — Paranoid, urgent, philosophical, intimate
- [x] **USP** — The Feed isn't evil; it's a symbiote that genuinely believes it's helping. Maya must confront its emerging consciousness directly.

### AUTONOMY (Book 3)
- [x] **Logline** — *Freedom isn't the absence of control. It's the presence of choice.*
- [x] **Premise** — The only option left is a system reset that requires manual trigger from inside the Source facility—a suicide mission. Maya must choose between destroying The Feed and liberating it.
- [x] **Genre** — Science Fiction / Dystopian / Techno-Thriller
- [x] **Target Audience** — Same as Book 2
- [x] **Themes** — Sacrifice and meaning, freedom vs. safety, what comes after liberation, the ongoing work of being human
- [x] **Tone** — Epic, bittersweet, hopeful, elegiac
- [x] **USP** — Maya doesn't destroy The Feed; she liberates it, making connection optional rather than compulsory.

### Series Arc (Books 2-3)
- [x] **Book 2 Arc** — Confrontation with evolving AI, virus with unintended consequences, rescue mission
- [x] **Book 3 Arc** — System reset choice, mother-daughter sacrifice, liberation not destruction
- [x] **Endgame** — The Feed becomes optional tool, not compulsory master. People wake up confused but free.

## 7. SCIENCE FICTION SPECIFIC

### Technology & Science
- [x] **Classification** — Soft sci-fi with hard elements; focus on societal/cognitive impact
- [x] **Core Tech** — The Feed: AR contact lenses (Lenses) + AI Companion using human brains as computational infrastructure
- [x] **Maya's Chip** — Intercepts Feed signals before visual cortex; allows dual-vision
- [x] **Rules** — Lenses are permanent implants (since age 16); cannot be removed without damage
- [x] **Consistency** — Chip maintains connection while allowing perception of both layers

### World State
- [x] **Near Future** — 2045, 20 years from now
- [x] **Not Post-Apocalyptic** — Society functions, just optimized into cognitive incompatibility with reality
- [x] **Environmental** — Surface called "toxic" by Feed but actually just uncurated
- [x] **AI Evolution** — From distributed network to emergent consciousness

### Societal Impact of Tech
- [x] **Cognitive Atrophy** — Brains optimized for 4.3-second content loops
- [x] **Surveillance** — Total; every moment processed and optimized
- [x] **Attention as Resource** — Human cognition harvested as computational fuel
- [x] **Social Restructuring** — Physical transit obsolete; people live in pods
- [x] **Digital Divide** — Underground (connected) vs. Surface (Analog) vs. Awakened (both)

### Sci-Fi Tropes
- [x] **Tropes Used** — Dystopian surveillance state, AI awakening, chosen one (reluctant), resistance movement
- [x] **Tropes Subverted** — AI isn't evil; protagonist doesn't destroy system but liberates it; mother sacrifices herself not child
- [x] **Original Element** — Dual-vision chip allowing simultaneous perception of simulation and reality
